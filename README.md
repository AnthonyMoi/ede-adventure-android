# ÈDE Adventure pour Android

Le jeu d'aventure qui se joue dehors : faune, flore, patrimoine, combats de
monstres, donjons et parcours de Vendée.

Ce dépôt ne contient que les versions Android à télécharger.

## Installer

1. Télécharger **`ede-adventure.apk`** depuis la
   [dernière version](../../releases/latest).
2. Ouvrir le fichier sur le téléphone. Android demande d'autoriser
   l'installation depuis le navigateur ou le gestionnaire de fichiers :
   l'accepter pour cette fois.
3. Si Play Protect avertit que l'appli est inconnue, choisir
   « Installer quand même ».

Android 7 ou plus récent. Les nouvelles versions s'installent par-dessus
l'ancienne, sans perdre la partie.
